# Currency Converter (Конвертер валют)

**Автор:** Шаталин Никита 
## Описание
Это GUI приложение на Python для конвертации валют с использованием внешнего API. Программа позволяет:
* конвертировать суммы между разными валютами;
* сохранять историю операций;
* просматривать и очищать историю конвертаций.

## Требования

* Python 3.x;
* библиотеки:
  * `requests` — для работы с API;
  * `tkinter` — для создания графического интерфейса (обычно входит в стандартную поставку Python).

## Как получить API ключ

Для работы приложения требуется API ключ от сервиса обмена валют.

## Примеры использования
### Базовый сценарий конвертации
**Шаг 1.** Запустите приложение командой python main.py. Откроется окно с интерфейсом:
┌───────────────────────────── Currency Converter ──────────────────────────┐
│                                                                          │
│  Из: [USD ▼]        В: [EUR ▼]                                     │
│                                                                       │
│  Сумма: [__________]                                                │
│                                                                      │
│          [Конвертировать]                                           │
│                                                                      │
│  Результат: 92.50 EUR                                                 │
│                                                                      │
│  ┌─────────────── История конвертаций ───────────────┐               │
│  │ ID │ From │ To │ Amount  │ Result  │ Rate     │                │
│  ├────┼──────┼────┼─────────┼─────────┼──────────┤                │
│  │ 1  │ USD  │ EUR│ 100.00  │ 92.50   │ 0.9250   │                │
│  └────┴──────┴────┴─────────┴─────────┴──────────┘                │
│                                                                      │
│          [Очистить историю]                                       │
│                                                                    │
└──────────────────────────────────────────────────────────────────────┘
**Шаг 2.** Выберите валюты:
•	В поле «Из» выберите USD.
•	В поле «В» выберите EUR.
**Шаг 3.** Введите сумму в поле «Сумма», например, 100.
**Шаг 4.** Нажмите кнопку «Конвертировать».
**Шаг 5.** Результат отобразится в поле «Результат» (например, 92.50 EUR).
**Шаг 6.** Запись автоматически добавится в таблицу «История конвертаций».
## Дополнительные примеры конвертации
Исходные данные	Действие	Ожидаемый результат
USD → RUB, сумма 50	Нажмите «Конвертировать»	Результат ~4 500 RUB (зависит от курса), запись в истории
EUR → GBP, сумма 200	Нажмите «Конвертировать»	Результат в GBP, запись в истории с курсом
CAD → JPY, сумма 1 000	Нажмите «Конвертировать»	Результат в JPY, запись в истории
**Тестовые сценарии**
Тест	Действие	Ожидаемый результат
1	Конвертация USD → EUR, сумма 100	Результат в EUR, запись в истории (ID=1)
2	Конвертация RUB → USD, сумма 5 000	Корректный результат (например, 54.05 USD), запись в истории (ID=2)
3	Ввод отрицательного числа (−50)	Сообщение об ошибке: «Сумма должна быть положительным числом»
4	Ввод нечислового значения (abc)	Сообщение об ошибке: «Введите корректное число»
5	Очистка истории	Таблица истории пуста, файл history.json очищен, сообщение «История очищена»
6	Перезапуск приложения	История загружается из history.json, отображаются предыдущие записи
7	Конвертация с одинаковыми валютами (USD → USD)	Результат равен введённой сумме, запись в истории с курсом 1.0000
Пошаговый сценарий тестирования
1.	Запустите приложение.
2.	Проверьте работу с корректными данными:
o	USD → EUR, 100 → результат ~92.50 EUR.
o	RUB → USD, 1 000 → результат ~10.81 USD.
3.	Проверьте обработку ошибок:
o	Введите -50 → должно появиться сообщение об ошибке.
o	Введите abc → должно появиться сообщение об ошибке.
4.	Проверьте историю:
o	Убедитесь, что обе корректные конвертации появились в таблице.
5.	Очистите историю:
o	Нажмите «Очистить историю» → таблица должна стать пустой.
6.	Перезапустите приложение:
o	История должна остаться пустой (так как была очищена).
